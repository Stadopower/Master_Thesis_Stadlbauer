Master Thesis working on detecting the Pre-Movement state of reaching and grasping, as well as walking movements, during a continous VR task. Participants were asked to manouver from table to table following pre-defined paths, placing two bottles at each table they arrive to.
The analysis focused on extracting MRCP and ERDS features from the EEG stream. Using it to try and detect the pre-movement state during this continous task. 

The main Analysis for the Master Thesis research is located in the jupyter notebooks. Further collected participants are ran in the .py files as I still collaborate with the researchgroup in writing papers from this project. A .py file for the LDA and SVM performances are still missing.
Furthermore, I am working on quantifying the quality of the EEG data for a Paper describing the collected data (EEG, Behavioral, Motion Capture)
